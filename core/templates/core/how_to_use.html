User Guide

How To Use

               Quick reference for using Removals Manager.

Basic Workflow
01

Find a Part

Use the home page dropdown to select a part and review its description, location data, drawing, sheet, revision, and notes.

02

Add or Edit Parts

Use Add Part or Edit Part to update part data. Keep drawing, sheet, revision, and notes accurate for planning use.

03

Manage Requirements

Add installation requirements like torque, seal, bond, HIRF, DCMA, or other notes tied to the selected part. Using Pl, it's helpful for planning to add flagnotes of the requirement

04

Create Planning Request

Select the needed parts, enter operation numbers, review the package, and generate the planning message.

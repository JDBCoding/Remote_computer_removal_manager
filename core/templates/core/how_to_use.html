How to Use Removals Manager

This page explains how to view parts, manage requirements, and build a Planning Request.

1) Find and View a Part

  • Go to Home.
  • Use the part list/search to locate the part number.
  • Select a part to view its details (DWG, SHT, REV, etc.).
  • The part’s Installation Requirements are shown with the part details.

2) Add a New Part Manually

  • From Home (or the Parts area), click Add Part.
  • Enter the part number and details (description, DWG, SHT, REV, etc.).
  • Save the part.

3) Edit an Existing Part

  • Find the part on the Home page.
  • Click Edit for that part.
  • Update the fields and save.

4) Add / Edit Installation Requirements

Requirements are attached to a specific part. These are things Planning needs to add or verify (Torque, Seal, Bond, HIRF, Retest, DCMA, etc.).

  • Open a part (or go to Edit for the part).
  • In the Installation Requirements section:
    • Choose the requirement type (Torque / Seal / Bond / etc.).
    • Add any notes if your form supports notes.
    • Use Add another (or the extra blank row) to add more requirements.
    • Use the delete checkbox to remove a requirement and save.
  • Save changes when done.

Create Planning Request

  • Go to Create Planning Request.
  • Enter the Job Number and any Notes / Special Instructions.
  • Find parts using the search box (no more scrolling forever).
  • Check the box next to each part you want included.
  • When you check a part, an OP input appears for that part—enter the OP if needed.
  • Click Submit Planning Request.

What the result does

  • Builds a formatted planning message including:
    • Job Number
    • Notes
    • Each selected part with DWG / SHT / REV
    • The part’s installation requirements list
  • The selected parts are preserved in the order you checked them.
